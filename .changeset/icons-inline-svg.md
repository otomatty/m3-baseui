Render Material Symbols as inline SVG so ligature names never flash as text while a webfont loads. The default entry ships only glyphs used by this repo; import `@m3-baseui/icons/all` for the full catalog. Drop the Google Fonts `<link>`; `filled` still selects FILL 1. `variant` and `weight` stay in the API for compatibility but glyphs are outlined weight 400.
